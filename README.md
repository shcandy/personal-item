# RHEIN TERMINAL · 模块化决策终端

一个以米白为主色调、参考《明日方舟》莱茵生命视觉思路设计的轻量网页工具台。
纯原生 HTML / CSS / JavaScript，无需构建、无需联网，双击 `index.html` 即可使用。

## 设计要点

- **米白基调**：`#f1eee4` 纸色底 + 淡琥珀色 `#c9a23c` 强调色 + 青灰辅助色
- **秩序感**：细网格背景、等宽字体读数、模块编号（M-01…M-08）、扫描线动效
- **毛玻璃**：所有模块卡片与弹窗使用 `backdrop-filter: blur + saturate` 的玻璃质感
- **模块化**：每个区块即一个独立功能单元，点击卡片运行对应功能

## 模块一览

| 编号 | 模块 | 状态 |
| --- | --- | --- |
| M-01 | 随机选择器 | ✅ 就绪 |
| M-02 | 专注计时（15/25/45 分钟） | ✅ 就绪 |
| M-03 | 掷骰子（1–3 枚） | ✅ 就绪 |

## 随机选择器（M-01）

- **内置预设**：25 种食物，按「饭 / 面 / 轻食 / 汤锅 / 小食」分类，可全选 / 清空 / 分类筛选
- **外部导入**：拖放或选择文件（`.csv` / `.txt` / `.json`），或直接粘贴文本
  - JSON：数组，或含 `items` / `options` / `data` / `list` 的对象
  - CSV：自动识别表头列（名称 / name / item 等），每行一项
  - TXT：每行一项，自动忽略空行与项目符号、编号
- **抽取选项**：抽取数量（1–10）、去重开关、抽取后消耗开关
- 结果滚轮动画、抽取历史（保留最近 12 条）、次数统计

所有数据（名单、历史、笔记等）仅存于当前浏览器的 localStorage。

## 使用

- 直接双击 `index.html`，或在命令行 `start index.html`
- 演示直达：`index.html?open=random`（可换成 `focus` / `dice` / `note` / `clock`）
